## Bagian-Bagian Interface

### 1. Komponent Section
Kumpulan **komponen siap pakai** seperti button, image, paragraph, text, input, dan lainnya.  
Contoh screenshot interface editor:  
<img src="/uploads/interface-component.png" alt="Komponent Section" width="100%" />

---

### 2. Blocks Section
Block adalah gabungan beberapa komponen menjadi satu unit.  
Tersedia block siap pakai seperti **column, boxed, card, listed**, dan lainnya.  
Contoh screenshot interface editor:  
<img src="/uploads/interface-blocks.png" alt="Blocks Section" width="100%" />

---

### 3. Library Section
Section adalah gabungan beberapa block menjadi satu layout.  
Tersedia section template siap pakai seperti **hero, about, list, galeri, header, produk**, dan lainnya.  
Contoh screenshot editor:  
<img src="/uploads/interface-section.png" alt="Library Section" width="100%" />

---

### 4. Navbar Section
Terletak di bagian atas interface, berisi fitur navigasi utama editor:

1. **Panel Hide/Show**: Menampilkan atau menyembunyikan panel sidebar dan properties  
2. **Undo / Redo**: Membatalkan atau memajukan perubahan terbaru  
3. **Preview**: Mode pratinjau landing page tanpa interface editor  
4. **Fullscreen**: Mode layar penuh untuk fokus bekerja  
5. **Mode Responsive**: Melihat tampilan di desktop, tablet, dan mobile  
6. **Save**: Menyimpan semua perubahan landing page  
7. **Zoom In / Out**: Memperbesar atau memperkecil tampilan pratinjau  
8. **Revision**: Kontrol versi untuk kembali ke perubahan sebelumnya  

---

### 5. Properties Panel
Panel ini digunakan untuk mengatur **properties** setiap komponen, block, atau section yang sedang dipilih.  
Properti yang muncul menyesuaikan dengan elemen yang dipilih.  

Untuk panduan lengkap pengaturan properties, lihat link berikut:
