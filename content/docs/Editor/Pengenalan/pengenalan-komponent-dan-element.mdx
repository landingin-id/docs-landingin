### Apa itu Komponen

Website bukan hanya tampilan – ini adalah **mesin konversi Anda**.  
Gunakan komponen yang tepat untuk **mengoptimalkan landing page** dan meningkatkan hasil penjualan.  

Komponen adalah **elemen terkecil pada landing page**, seperti **button, text, header, image**, dan lainnya, yang membentuk informasi untuk tujuan konversi.  

Web builder Landingin adalah **kanvas digital Anda**. Setiap komponen memberi kebebasan desain penuh, dari konsep awal hingga masterpiece.

---

### Mengakses Komponen

Pada **Interface Komponent Section**, klik **ikon cube**. Akan muncul **2 tab utama**:  
- **Components** – daftar semua komponen individu  
- **Blocks** – kumpulan komponen yang sudah dirangkai menjadi blok siap pakai

### Kelompok Komponen

Komponen dikelompokkan menjadi **6 kategori utama**:

1. **Base**  
2. **Elements**  
3. **Embeds**  
4. **Widgets**  
5. **Bootstrap**  
6. **Plugins**

---

### 1. Komponen Base

Base adalah komponen fundamental yang membentuk struktur landing page:  
- Heading, Image, HTML Button, Paragraph, Form, Input, Textarea, Selectbox, Checkbox, Radio Button, Link, List, Table, Audio

---

### 2. Komponen Elements

Elements berisi komponen tambahan untuk memperluas fungsionalitas:  
- SVG Icon, Custom Code  
> Catatan: Akan ada update penambahan komponen di kategori ini.

---

### 3. Komponen Embeds

Digunakan untuk menyematkan konten eksternal seperti:  
- Embed HTML, Embed Script  
> Catatan: Kategori ini akan diperluas di update mendatang.

---

### 4. Komponen Widgets

Widgets mempermudah integrasi dengan layanan pihak ketiga:  
- Google Maps, Embed Video, Open Street Map

---

### 5. Komponen Bootstrap

Berisi komponen berbasis framework Bootstrap, cocok untuk membangun layout responsif:  
- Container, Grid Row, Button, Button Group, Alert, Card, List Group, Badge

---

### 6. Komponen Plugins

Editor Landingin mendukung **instalasi plugin** untuk menambah fungsionalitas:  
- Default plugin: Contact Form  
> Catatan: Fitur ini akan tersedia sepenuhnya di update mendatang.

---

Dengan memahami setiap komponen, Anda dapat **menggabungkan, menyesuaikan, dan merancang landing page** dengan cepat, konsisten, dan profesional.
