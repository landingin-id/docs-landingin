### Memulai

1. **Login ke Dashboard Landingin**
   Login melalui aplikasi, download dan install aplikasi terlebih dahulu, link download [Download App](https://landingin.id/halaman-download-67).

2. **Akses Halaman Landing Page**  
   Navigasi ke **Landing Page → Pilih Domain → Pilih Halaman** yang ingin diedit.

3. **Buka Editor**  
   Klik tombol **“Pergi ke Editor”** untuk masuk ke halaman editor visual.

---

### Auto Login Editor

Setelah mengklik tombol **“Pergi ke Editor”**, Anda akan secara otomatis diarahkan ke **Landingin Editor**.  
Di sini, Anda dapat:

- Mengubah teks langsung di halaman (inline editing)  
- Mengunggah dan mengganti gambar/media  
- Menyesuaikan elemen secara visual tanpa perlu menulis kode  
- Menyimpan perubahan secara instan dengan **auto-save**  

---

Dengan fitur ini, proses **mengedit konten menjadi cepat, mudah, dan aman**, sehingga Anda bisa fokus pada desain dan konversi halaman.
