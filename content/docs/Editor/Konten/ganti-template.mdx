### Penjelasan

Pada project `landingin-saas`, fitur **Ganti Template** digunakan untuk
mengubah template pada:

- **Site** secara keseluruhan
- **Page** tertentu di dalam site

Template dipilih dari daftar template yang tersedia, lalu diterapkan dari
halaman khusus pemilihan template.

---

### Di Mana Fitur Ini Digunakan

Saat ini ada dua alur utama:

#### 1. Ganti Template Site
Alur ini dipakai untuk mengganti template utama dari sebuah site.

#### 2. Ganti Template Page
Alur ini dipakai untuk mengganti template pada satu page tertentu
tanpa harus mengganti template seluruh site.

---

### Cara Mengganti Template

#### A. Ganti Template Site

1. Masuk ke dashboard Landingin
2. Buka halaman **Sites**
3. Pilih site yang ingin dikelola
4. Pada halaman detail site, klik tombol **Ganti Template**

Setelah itu Anda akan diarahkan ke halaman pemilihan template site.

Di halaman ini, Anda dapat:
- Melihat **template saat ini**
- Memilih **template baru**
- Melihat daftar template berdasarkan **segment** dan **group**
- Membuka **demo template**
- Menjalankan aksi **Ganti Template Site**

#### Langkah mengganti template site

1. Buka halaman **Pilih Template**
2. Gunakan filter **segment** jika diperlukan
3. Gunakan filter **group** untuk mempersempit daftar template
4. Klik salah satu template yang ingin dipakai
5. Klik tombol **Ganti Template Site**

Jika berhasil, sistem akan menyimpan template baru lalu mengarahkan Anda
kembali ke halaman detail site.

---

#### B. Ganti Template Page

1. Masuk ke halaman detail site
2. Buka daftar page pada site tersebut
3. Pilih page yang ingin diubah
4. Klik tombol **Ganti Template** pada page terkait

Setelah itu Anda akan masuk ke halaman pemilihan template khusus untuk page.

Di halaman ini, Anda dapat:
- Melihat nama page
- Melihat slug page
- Memilih template dari daftar yang tersedia
- Menjalankan aksi **Terapkan Template ke Page**

#### Langkah mengganti template page

1. Buka halaman pemilihan template page
2. Pilih **segment** dan **group** jika diperlukan
3. Klik template yang ingin dipakai
4. Klik tombol **Terapkan Template ke Page**

Jika berhasil, sistem akan menyimpan template baru untuk page tersebut
dan mengarahkan Anda kembali ke halaman site.

---

### Informasi Yang Tersedia Pada Halaman Template

Pada halaman pemilihan template, biasanya Anda akan melihat:
- Nama template
- Label **Gratis** atau **Premium**
- Segment dan group template
- Tombol atau link **Lihat demo**
- Status template yang sedang dipilih

Beberapa template ditandai sebagai **Premium**. Sesuai tampilan aplikasi,
template premium ditujukan untuk paket berbayar.

---

### Tombol Yang Perlu Diperhatikan

- **Ganti Template Site**: menerapkan template ke level site
- **Terapkan Template ke Page**: menerapkan template ke page tertentu
- **Kembali ke Site**: kembali ke halaman detail site tanpa menyimpan perubahan

### Catatan

- Alur ganti template saat ini dilakukan dari halaman detail `Site` atau `Page`, bukan dari menu `Themes`.
- Anda bisa memakai filter `segment` dan `group` untuk menemukan template yang lebih sesuai.
- Jika template belum dipilih, tombol aksi utama tidak bisa dijalankan.
- Untuk template premium, pastikan paket akun Anda sudah sesuai sebelum mencoba menggunakannya.
