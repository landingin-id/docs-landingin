### Tandai Order sebagai Selesai

Fitur **Set As Complete** digunakan untuk menandai bahwa sebuah order telah **diselesaikan sepenuhnya** dan seluruh proses pemesanan telah selesai dalam satu siklus order.

Dengan menandai order sebagai *complete*, sistem akan menganggap bahwa tidak ada lagi proses lanjutan yang perlu dilakukan untuk order tersebut.

### Kapan Order Perlu di-Set Complete

Order sebaiknya ditandai sebagai *complete* apabila:

1. Pembayaran telah diterima dan dikonfirmasi
2. Produk telah diserahkan kepada pelanggan  
   - Produk digital: link download telah diberikan
   - Produk fisik: barang telah dikirim atau diserahkan
3. Tidak ada kendala atau komplain lanjutan dari pelanggan

### Fungsi Set As Complete

Menandai order sebagai *complete* memiliki beberapa manfaat, antara lain:

1. 🧾 Menutup siklus pemesanan  
   Menandakan bahwa seluruh tahapan order telah selesai diproses.

2. 📊 Membantu pencatatan dan pelaporan  
   Order yang telah selesai dapat dipisahkan dari order aktif atau yang masih perlu ditindaklanjuti.

3. 🛍️ Manajemen order lebih rapi  
   Memudahkan Anda dalam memfilter dan mengelola order berdasarkan statusnya.

4. 🔒 Menghindari kesalahan follow up  
   Order yang sudah selesai tidak akan tertukar dengan order yang masih menunggu proses.

### Catatan

- Untuk metode pembayaran **Bank Transfer**, pastikan pembayaran telah dikonfirmasi terlebih dahulu sebelum menandai order sebagai *complete*.
- Setelah order di-set *complete*, status order tidak dapat dikembalikan ke tahap sebelumnya.

Pastikan Anda melakukan pengecekan data order sebelum menggunakan fitur ini.
