### Penjelasan

Setiap site memiliki template utama yang digunakan sebagai dasar tampilan.

Jika Anda ingin mengubah tampilan site tanpa membuat site baru, gunakan fitur
**Ganti Template** pada halaman detail site.

Fitur ini berguna ketika Anda ingin:
- Mengubah desain utama site
- Menyesuaikan tampilan dengan campaign baru
- Mengganti struktur visual tanpa membuat site dari awal

---

### Cara Ganti Template Site

#### 1. Buka Detail Site
Masuk ke halaman **Sites**, pilih site yang ingin diubah, lalu klik **Manage**.

#### 2. Temukan Bagian Template
Pada tab **Overview**, cari kartu informasi **Template**.

Di bagian ini sistem menampilkan:
- Nama template yang sedang digunakan
- Segment template
- Group template

#### 3. Klik Ganti Template
Klik tombol **Ganti Template** untuk membuka halaman pemilihan template site.

<img src="/uploads/ganti-template-button.jpg" alt="Halaman tambah site baru" width="100%" />

#### 4. Pilih Template Baru
Pada halaman pemilihan template:
- Pilih template yang ingin digunakan 
- Gunakan filter segment atau group jika diperlukan
- Perhatikan label **Gratis** atau **Premium**

<img src="/uploads/pilih-template-page.jpg" alt="Halaman tambah site baru" width="100%" />

Jika template yang dipilih termasuk premium, pengguna paket gratis mungkin tidak dapat menggunakannya.

#### 5. Simpan Perubahan
Setelah template baru dipilih, lalu selanjutnya klik tombol **Ganti Template Site**

<img src="/uploads/klik-ganti-template.jpg" alt="Halaman tambah site baru" width="100%" />

Setelah berhasil, template site akan diperbarui sesuai pilihan Anda.

---

### Dampak Setelah Template Diganti

Mengganti template dapat memengaruhi:
- Struktur tampilan halaman utama
- Susunan section atau layout
- Kesesuaian konten lama terhadap template baru

Karena itu, setelah mengganti template, sebaiknya lanjutkan pengecekan di editor.

---

### Lanjutkan Ke Editor

Setelah template diganti, Anda dapat kembali ke halaman detail site lalu klik
**Pergi Ke Editor** untuk menyesuaikan:
- Teks
- Gambar
- Tata letak
- Section yang digunakan

### Catatan

- Template premium hanya tersedia untuk paket tertentu.
- Setelah mengganti template, cek ulang isi site sebelum dipublish ke publik.
- Jika perubahan tampilan cukup besar, Anda bisa lakukan penyesuaian tambahan di editor.
