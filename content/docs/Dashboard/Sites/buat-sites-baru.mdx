### Buat Site Dengan Subdomain

Pada halaman **Sites**, Anda dapat membuat site baru sekaligus menentukan **subdomain** yang akan digunakan.

Saat membuat site, sistem juga akan menyiapkan domain dalam format:
**namasite.domain-host**

Keterangan:
- **namasite** → nama subdomain yang Anda tentukan
- **domain-host** → host utama yang disediakan sistem ( dalam hal ini **landingin.id**)

Subdomain ini dibuat otomatis saat proses pembuatan site selesai, sehingga Anda tidak perlu melakukan konfigurasi teknis tambahan.

> Jumlah site yang dapat Anda buat akan mengikuti limit paket yang sedang digunakan.  
> Jika batas paket sudah tercapai, sistem akan menampilkan pemberitahuan saat proses pembuatan site.

### Kustom Domain

Anda juga dapat mengganti dari **namasite.domain-host** ke **namasite.com** atau extension lainya melalui fitur [kustom domain](/docs/custom-domain).

### Langkah Membuat Site Baru

Berikut langkah-langkah untuk membuat site baru sesuai alur pada dashboard:

#### 1. Buka Halaman Sites
Masuk ke dashboard, lalu buka halaman **Sites**. Setelah itu klik tombol **Create New Site**.

<img src="/uploads/create-site.jpg" alt="Form tambah landing page baru" width="100%" />

#### 2. Pilih Template dan Tentukan Subdomain
Pada halaman **Buat Site Baru**, pilih template yang ingin digunakan, lalu isi nama subdomain pada kolom yang tersedia.

<img src="/uploads/site-pilih-template.jpg" alt="Input nama subdomain" width="100%" />

Pastikan nama subdomain:
- Mudah diingat ( contoh : bromo menjadi **bromo.landingin.id** )
- Relevan dengan brand atau produk Anda
- Belum digunakan oleh pengguna lain

Template yang dipilih akan menjadi dasar tampilan site saat pertama kali dibuat.

#### 3. Klik Create Site
Setelah template dipilih dan nama subdomain diisi, klik tombol **Create Site**.

<img src="/uploads/klik-create-site.jpg" alt="Proses instalasi landing page" width="100%" />

Sistem akan secara otomatis:
- Membuat site baru
- Mendaftarkan subdomain untuk site tersebut
- Menghubungkan template yang dipilih ke site baru

Setelah berhasil, Anda akan diarahkan kembali ke halaman **My Sites**. seperti screenshot dibawah ini : 

<img src="/uploads/halaman-dashboard.jpg" alt="Halaman tambah site baru" width="100%" />

#### 4. Edit Konten & Tampilan

Setelahnya, apabila anda ingin mengedit konten beserta tampilan terkait sites yang baru saja anda buat,
klik button **Pergi ke Editor** seperti gambar dibawah ini :

<img src="/uploads/klik-ke-editor.jpg" alt="Halaman tambah site baru" width="100%" />

Selanjutnya anda akan diarahkan ke halaman editor landingin. 
untuk panduan kustomisasi dengan editor landingin anda bisa pergi ke halaman [Panduan Editor](/docs/Editor)

---

### Status Setelah Site Dibuat

Setelah proses selesai, site akan muncul di halaman **My Sites** dengan status **draft**.

Artinya:
- Site sudah berhasil dibuat
- URL site sudah tersedia
- Site belum dipublikasikan ke publik

### Catatan

- Site baru memerlukan pemilihan template sebelum dapat dibuat.
- Penulisan subdomain sebaiknya diperiksa kembali sebelum klik **Create Site**.
- Setelah site dibuat, Anda masih dapat membuka halaman detail site untuk **Publish**, **Unpublish**, atau menggunakan **Kustom Domain** bila fitur tersebut tersedia pada paket Anda.
