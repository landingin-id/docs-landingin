---
title: Hapus Site
description: Menghapus site secara permanen melalui halaman detail site.
---

### Penjelasan

Fitur **Hapus Site** digunakan untuk menghapus site beserta konten yang terkait
secara permanen.

Karena bersifat permanen, fitur ini sebaiknya digunakan hanya jika:
- Site sudah tidak digunakan
- Anda ingin membersihkan site percobaan
- Site dibuat salah dan perlu dihapus

---

### Cara Menghapus Site

<img src="/uploads/hapus-sites.jpg" alt="Pengaturan kustom domain pada site" width="100%" />

1. Buka halaman **Sites**
2. Pilih site yang ingin dihapus
3. Klik tombol **Manage**
4. Buka bagian **Danger Zone** pada halaman detail site
5. Klik tombol **Delete Site**
6. Konfirmasi penghapusan jika sistem meminta persetujuan

Jika proses berhasil, site akan dihapus dari dashboard.

---

### Syarat Penting Sebelum Menghapus

Pada halaman detail site, tombol **Delete Site** hanya dapat digunakan
saat status site masih **draft**.

Artinya:
- Jika site masih **published**, Anda perlu melakukan **Unpublish** terlebih dahulu
- Setelah status kembali ke **draft**, barulah site dapat dihapus

---

### Yang Terjadi Saat Site Dihapus

Saat site dihapus, sistem akan:
- Menghapus data site dari dashboard
- Melepas relasi domain aktif dari site tersebut
- Menghapus konten site dari layanan terkait bila tersedia

Karena proses ini bersifat permanen, pastikan tidak ada data penting yang masih dibutuhkan.

### Catatan

- Hapus site hanya dilakukan jika Anda benar-benar yakin.
- Pastikan site sudah tidak dipakai untuk promosi, iklan, atau campaign aktif.
- Jika ragu, gunakan **Unpublish** terlebih dahulu sebelum memutuskan menghapus site.
