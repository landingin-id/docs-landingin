### Tentang produk

Node Pro adalah layanan paket berbayar yang kami hadirkan untuk para pelaku bisnis digital baik marketer / creator, advertiser yang sudah mahir dan berpengalaman. 
<b>Uji coba 7 hari gratis</b> bisa anda coba tanpa komitmen sebelum memutuskan untuk berlangganan.

### Fitur diberikan :
1. Editor Landing Page
2. 10GB Disk Space
3. Unlimited Bandwith
4. Lifetime Update

### Limitasi Fitur :

Pada Node Creator perbedaan ada pada jumlah limitasi yang diberikan, anda bisa melihat detailnya dibawah ini :


| Fitur             | Limitasi       |
| ------------------- | ------------ |
| Domain              | 6            |
| Halaman      | Unlimited           |
| Kustom Domain              | Tersedia          |
| Ai Asistant Editor              | Tersedia          |
| Ai Copy Builder             | Tersedia          |
| Ai Design Builder              | Tersedia          |

### Penjelasan Limitasi

1. <b>Domain</b> : anda hanya memiliki 6 subdomain / domain pada layanan ini.
2. <b>Halaman</b> : Kami tidak memberikan batasan jumlah halaman yang dapat dibuat pada layanan ini.
3. <b>Kustom domain</b> : Ganti nama domain dengan extension seperti .com, .id, .net dan lain lain.
4. <b>Ai Asistant Editor</b> : Tools Pendukung ai yang tersedia pada editor landingin.
5. <b>Ai Copy Builder</b> : Tools generate LP pake ai dengan fokus ke copy dan konversi penjualan.
6. <b>Ai Design Builder</b> : Tools convert desain ke LP pake ai, buat kamu yang bisa desain.
