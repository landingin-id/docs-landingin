### Tentang produk

Node Creator adalah layanan paket berbayar yang kami hadirkan untuk para pelaku bisnis digital baik marketer / advertiser yang sudah mulai menghasilkan cuan. 


### Fitur diberikan :

1. 10.000 Visitor / Month
2. Unlimited Bandwith
3. Akses Ke Semua Fitur Editor
4. A/B Testing


### Limitasi Fitur :

Pada Node Creator perbedaan ada pada jumlah limitasi yang diberikan, anda bisa melihat detailnya dibawah ini :


| Fitur             | Limitasi       |
| ------------------- | ------------ |
| Domain              | 3           |
| Halaman      | 8 Landing Page / Domain          |
| Kustom Domain              | Tersedia          |
| Ai Asistant Editor              | Tersedia          |
| Ai Copy Builder             | Tersedia          |
| Ai Design Builder              | Tersedia          |
| Akses Template Kustom              | Tersedia          |

### Penjelasan Limitasi

1. <b>Domain</b> : anda hanya memiliki 2 subdomain / domain pada layanan ini.
2. <b>Halaman</b> : Kami memberikan limitasi jumlah landing page yang bisa dibuat pada layanan ini.
3. <b>Kustom domain</b> : Ganti nama domain dengan extension seperti .com, .id, .net dan lain lain.
4. <b>Ai Asistant Editor</b> : Tools Pendukung ai yang tersedia pada editor landingin.
5. <b>Ai Copy Builder</b> : Tools generate LP pake ai dengan fokus ke copy dan konversi penjualan.
6. <b>Ai Design Builder</b> : Tools convert desain ke LP pake ai, buat kamu yang bisa desain.
7. <b>Akses Template Kustom</b> : Gunakan koleksi template premium yang sudah ada untuk halaman anda.
