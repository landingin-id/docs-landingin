## Pengenalan

Landingin adalah platform pembuat landing page **otomatis** dalam hitungan menit. Setiap halaman sudah disertai **rancangan desain awal** beserta **copywriting siap pakai**, sehingga Anda dapat langsung memulai.

Berikut **empat tahapan ringkas** untuk memulai:

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
  <Step>
  #### 1. Tentukan Layanan
  Pilih jenis layanan yang sesuai dengan kebutuhan Anda.
  <img src="/uploads/harga-paket.png" alt="Tentukan Layanan" width="100%" />

  <Cards>
    <Card href="/docs/Layanan#opsi-layanan" title="Uji Coba 7 Hari">
      Nikmati uji coba fitur premium selama 7 hari untuk jenis layanan berbayar.
    </Card>
    <Card href="/docs/Layanan#opsi-layanan" title="Langsung Berlangganan">
      Langsung berlangganan dan lanjutkan ke halaman pembayaran sebelum menentukan domain.
    </Card>
  </Cards>
  </Step>

  <Step>
  #### 2. Tentukan Domain
  Pilih nama domain untuk landing page Anda. Bisa berupa subdomain seperti `example.landingin.id` atau gunakan [custom domain](/docs/fitur_kustom_domain).  
  <img src="/uploads/pilih-domain.png" alt="Tentukan Domain" width="100%" />
  </Step>

  <Step>
  #### 3. Pilih Metode Pembayaran
  Langkah ini **terskip jika memilih layanan gratis**. Tentukan metode pembayaran yang diinginkan.  
  <img src="/uploads/pilih-pembayaran.png" alt="Pilih Metode Pembayaran" width="100%" />
  </Step>

  <Step>
  #### 4. Informasi Pembayaran
  Setelah memilih layanan berbayar, nomor **Virtual Account** dan informasi pembayaran akan muncul. Lakukan pembayaran untuk melanjutkan setup.  
  <img src="/uploads/pilih-pembayaran.png" alt="Informasi Pembayaran" width="100%" />
  </Step>

  <Step>
  #### 5. Setup Landing Page
  Setelah pembayaran berhasil, sistem akan otomatis menyiapkan landing page Anda:  
  - Pendaftaran nama domain  
  - Konfigurasi database  
  - Setup HTTPS & sertifikat SSL  
  - Konfigurasi editor  
  <img src="/uploads/setup-landingpage.png" alt="Setup Landing Page" width="100%" />
  </Step>

  <Step>
  #### 6. Setup Berhasil
  Landing page berhasil disiapkan. Tombol untuk **kelola landing page** atau **pratinjau situs** akan muncul.  
  <img src="/uploads/setup-landingpage-success.png" alt="Setup Berhasil" width="100%" />
  </Step>

  <Step>
  #### 7. Domain Resolving
  Setelah setup berhasil, tunggu maksimal 1 jam agar **propagasi domain** selesai dan sertifikat SSL aktif.  
  <img src="/uploads/propagation.png" alt="Domain Resolving" width="100%" />
  </Step>

  <Step>
  #### 8. Go Online
  Domain telah resolve dan landing page siap diakses. Lanjutkan dengan **mengedit konten** melalui [editor Landingin](/docs/fitur_editor).  
  <img src="/uploads/go-online.png" alt="Go Online" width="100%" />
  </Step>
</Steps>

---

### Ringkasan Tahapan

1. **Tentukan Layanan**  
   Pilih antara **Uji Coba 7 Hari** atau **Berlangganan Langsung** sesuai kebutuhan.  

2. **Tentukan Domain**  
   Pilih subdomain default atau custom domain agar landing page dapat diakses publik.  

3. **Setup Landing Page**  
   Sistem otomatis menyiapkan semua konfigurasi teknis sehingga landing page siap publish.  

4. **Go Online**  
   Landing page live dan siap diedit menggunakan editor visual Landingin.
